# MemeAgotchi — Bug & Discrepancy Audit (Pre-Unification → Fixed)

Audited on **2026-11-20** across `02-web-app-source` and `03-handheld-simulator-source`.

| # | Severity | Source | Bug / Discrepancy | Fix in Unified Monorepo |
| :- | :--- | :--- | :--- | :--- |
| 1 | **Critical** | `02` + `03` | **Polling decay wipeout:** `tick()` applied `Math.round()` to stats on every poll (5s / 20s) and overwrote `lastTickAt`, erasing fractional deltas (`< 0.5`) so stats never decayed while a tab stayed open! | Store stats as floats internally in `GameState`; round only in `toView()`. Covered by tick-composition unit tests. |
| 2 | **Critical** | `02` | **`LabelMatch` mid-game reset:** `<LabelMatch key={Date.now()} ... />` inside `render()` unmounted and reset the game on every parent re-render (every 15s tick or refetch). | Stable component key + explicit "Play Again" key counter. |
| 3 | **Critical** | `02` | **`MemeDodge` timer leaks & double `onDone`:** 3 `setInterval`s had no unmount cleanup, `stateRef.current.over` raced with React state updater, and timer + collision could fire `onDone` twice. | Proper `useEffect` interval lifecycle with unmount cleanup, single `finishedRef` guard, and keyboard (`←`/`→`/`A`/`D`) + touch support. |
| 4 | **Critical** | `02` | **Unowned cosmetic equip exploit:** `equipCosmetic` never checked `cosmeticsOwned`, allowing equipping any item for free. | Server-side ownership check enforced in `game-core`. |
| 5 | **High** | `02` + `03` | **Infinite Happiness farm via re-equipping:** Equipping/unequipping any cosmetic repeatedly granted `+5 Happiness` every time (GDD §2: first wear only). | Track `firstWornCosmetics` in state; grant `+5 Happiness` only on first wear per cosmetic. |
| 6 | **High** | `03` | **Care/Voice XP stuck at Stage 1 visual:** `care` (`feed`/`groom`/`play`) and `talk` added XP without checking stage-up or updating `displayStage`, leaving evolved pets visually stuck at Stage 1 Blob until Stage 3 Nostalgia unlocked. | Centralized `awardXp()` helper updates stage, `displayStage`, evolution event log, and celebration speech across all actions. |
| 7 | **High** | `02` + `03` | **`@hatch/space-sdk` lock-in:** Both `package.json` files referenced `/opt/hatch/.../space-sdk.tgz`, making local runs and independent deploys impossible. | Replaced with clean `packages/rpc-sdk` + unified Node 22 HTTP/SQLite `apps/server`. |
| 8 | **High** | `02` + `03` | **Offline floor bug:** `Math.max(25, clamp(v))` could artificially *raise* a stat that was already `< 25` before going offline, and sleep→wake transitions over long offline durations weren't split accurately. | Offline floor uses `Math.max(Math.min(startVal, 25), clamp(v))`; sleep→wake splits elapsed hours cleanly at Energy = 80. |
| 9 | **Medium** | `02` | **Missing auto-sleep at Energy 0 & missing Nov 17 Energy retuning:** `02` never auto-slept at Energy 0 and still used `-4/hr` / `-15` Play while `03` used `-1/hr` / `-5` Play / `+20/hr` sleep. | Unified retuned math + auto-sleep at Energy 0 in `game-core`. |
| 10 | **Medium** | `03` | **Duplicate belly feeding & missing meme captions:** `03` allowed feeding the same meme into multiple belly slots simultaneously and stripped the real meme captions. | Prevent duplicate meme in belly; unified full seed catalog with captions across both apps. |
| 11 | **Medium** | `02` + `03` | **Secret moves had zero gameplay effects:** Unlocking secret words only displayed text; none modified game mechanics. | Wired live gameplay effects for all 10 launch secret moves (`stonks`, `doge`, `chad`, `rickroll`, `sus`, `rizz`, `no cap`, `l + ratio`, `mid meme`, `based and correct`). |
| 12 | **Medium** | `02` + `03` | **Stage 5 Nostalgia aura rule (GDD Decision #2):** `Monster` only received `displayStage`, hiding Stage 5 aura when displaying an earlier stage. | Pass both `actualStage` and `displayStage`; Stage 5 aura always renders when `actualStage === 5`. |
| 13 | **Medium** | `02` + `03` | **Missing GDD features:** No real ≤5 MB file upload (Decision #5), no meme/label report button with 3-report auto-hide (Decisions #5 & #6), no `rotten` 7-day label penalty, no post-digestion viral backflow, and no SSRF protection on `postMemeFromUrl`. | Implemented all of them in `game-core` + `apps/server` + `web-companion`. |
| 14 | **Low** | `02` | **Toast timeout race & stale belly countdowns:** Overlapping `setTimeout`s cleared newer toasts early; belly timers only refreshed every 15s. | Managed toast timer ref + 1-second live countdown ticker when belly/cooldowns are active. |
| 15 | **Low** | `02` + `03` | **`LabelMatch` stale `moves` closure & `03` `postMemeFromUrl` SSRF risk:** `moves` was off by 1 inside `setTimeout`; URL fetcher didn't block private/localhost IPs. | Fixed closure + added URL hostname/IP safety guard on `postMemeFromUrl`. |
