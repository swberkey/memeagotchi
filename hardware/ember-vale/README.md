# Ember Vale

A top-down action-adventure addon for an ESP32-S3 handheld with an ST7789V2
320x240 LCD, a d-pad and X / O / Start buttons. The host app launches it like
a module; it saves to a folder in flash and leaves the coins it earned there
for the host to cash out.

The hero, world, enemies, names and art are all original.

## What's in the world

- **Overworld:** 24 screens on a 6x4 grid: Craggy Heights, Cinderspire
  Slopes, Windy Pass, Old Barrow (graveyard), Wailing Field, Hollow Wood,
  Pinewatch, Mossy Grove, Breezy Meadow, Fairy Ring Meadow, Crow's Gate,
  Mirror Lake, Bramblewood, Thicket Road, Willowmere (two town screens),
  Riverbend, Sunscar Dunes, Fernhollow, Pebble Field, Southfields, Shell Shore,
  Dustmere and Bonedry Basin (desert).
- **Willowmere:** the town, with a pond, a statue and three townsfolk (Elder
  Rowan, Granny Mabel and Tamsin), plus Odo the fisher and Marlo's Shop. The
  shop sells bombs (20), arrows (15), a heart refill (10) and one heart
  container (150).
- **Pebble Cave:** two rooms. The boomerang is in the depths.
- **Bramblekeep:** the first castle, 8 rooms. It holds the bomb bag, the
  bow, a key and the boss key, and has a moat court and a pit gallery. Its
  boss is Thornback, an armoured beetle that the boomerang stuns and bombs
  hurt. Beating it gives the Sun crystal.
- **Cinderspire:** the second castle, 9 rooms. It has an eye switch to shoot,
  spike walks, ember pits, a needle maze, a key, the boss key and a coin
  purse. Its boss is the Wisp, and beating it gives the Moon crystal.
- **Hearts:** you start with 3. There are 3 hidden heart containers (Glimmer
  Grotto, Crag Hollow and Barrow Crypt), 2 from the bosses and 1 in the shop,
  for 9 in all.
- **Secrets:** paler bushes can be cut and cracked rock can be bombed. The
  Fairy Spring sits behind a bush ring in Fairy Ring Meadow and refills your
  hearts. The Silly Vault, the meme room, is behind a cracked wall in Bonedry
  Basin.
- **Coins:** gold ones are worth 1, silver 5 and red 20. They lie around the
  world, drop from enemies, bushes and grass, and the purse in Cinderspire
  holds 50.

## Controls

| Button | In play | In menus |
|---|---|---|
| D-pad | move | move cursor |
| X | sword, talk, read, open | confirm |
| O | use the selected item (bombs, bow, boomerang) | back |
| Start | inventory, map and pause (SAVE / SAVE & EXIT) | close |

Save & Exit writes the files and returns control to the host app.

## Layout

```
core/                 portable C99 game (no hardware code)
  ember_vale.h        public API: ev_init / ev_update / ev_render / ev_save / ev_coins
  game.c entities.c render.c save.c
  gen_assets.[ch] gen_world.[ch]   generated by tools/build.py, do not edit
tools/                Python generators for art and world (needs Pillow)
assets/meme.png       the Silly Vault picture (swap it any time)
assets/preview/       full maps of every area, rendered by build.py
esp-idf/components/ember_vale/   ESP-IDF component (LCD, buttons, files, launch API)
esp-idf/example_host/            tiny host app that mounts flash and launches the game
platform/web/         browser emulator (Emscripten)
platform/sdl/         desktop build (SDL2)
platform/test/        headless test library and the playtest bot
```

## Building

**Regenerating the art and world.** You only need this after editing
`tools/*.py` or `assets/meme.png`. The generated files are already in
`core/`.

```
pip install pillow
python3 tools/build.py            # also writes assets/preview/*.png
```

**ESP-IDF (v5.3 or newer, target esp32s3).**

```
cd esp-idf/example_host
idf.py set-target esp32s3
idf.py menuconfig                 # "Ember Vale" menu: pins, panel orientation, save folder
idf.py build flash monitor
```

The example assumes an N16R8 module (16 MB flash, 8 MB octal PSRAM). Its
partition table has a 3 MB app slot and a 1 MB FAT partition called
`storage`, mounted at `/storage`. The game binary is about 0.5 MB.

**Browser emulator.**

```
cd platform/web && ./build.sh     # needs emsdk; writes ember_vale_emulator.html
```

Open the HTML file in any browser. It uses keyboard, touch and gamepad
input, and saves to the browser's storage.

**Desktop (SDL2).**

```
cd platform/sdl
cc -O2 -std=c99 -I../../core ../../core/*.c main.c $(sdl2-config --cflags --libs) -o ember_vale
```

**Playtest bot.** This builds a headless library and plays the whole game,
writing screenshots and a summary.

```
cd platform/test && make && python3 bot.py /tmp/run --god
```

## Wiring (Kconfig defaults, all changeable in menuconfig)

| Signal | GPIO | | Button | GPIO |
|---|---|---|---|---|
| LCD SCLK | 12 | | Up | 4 |
| LCD MOSI (SDA) | 11 | | Down | 5 |
| LCD CS | 10 | | Left | 6 |
| LCD DC | 9 | | Right | 7 |
| LCD RESET | 14 | | X | 15 |
| LCD backlight | 13 | | O | 16 |
| | | | Start | 17 |

- Buttons are active low with internal pull-ups, so wire each one between
  its GPIO and GND.
- The LCD runs on SPI2 at 40 MHz. Short wiring often runs at 80 MHz.
- The panel defaults are: colours inverted (most ST7789V2 boards need this),
  X/Y swapped and X mirrored for landscape.
- If the picture is upside down or mirrored, flip `EV_LCD_MIRROR_X` /
  `EV_LCD_MIRROR_Y`. If the colours look like a negative, flip
  `EV_LCD_INVERT`. If red and blue are swapped, set `EV_LCD_BGR`.
- Avoid GPIO 26 to 37 on N16R8 modules, because the flash and octal PSRAM
  use them.

**How it draws.** The game renders the frame in bands of 40 lines into two
DMA buffers in internal RAM. One band is drawn while the other is being
sent, so it needs no framebuffer and no PSRAM. Game logic runs at a fixed
60 Hz and skips drawing if a frame runs late.

## Launch API (`ember_vale_esp.h`)

```c
#include "ember_vale_esp.h"

ember_vale_config_t cfg = EMBER_VALE_CONFIG_DEFAULT();
cfg.save_dir = "/storage/adventure";      // NULL = CONFIG_EV_SAVE_DIR
// Optional: reuse the host's own panel and button reader
// cfg.panel = my_panel; cfg.panel_io = my_io;
// cfg.read_buttons = my_read; cfg.buttons_ctx = my_ctx;   // return EV_BTN_* bits

ember_vale_result_t res;
ESP_ERROR_CHECK(ember_vale_run(&cfg, &res));  // blocks until Save & Exit
printf("wallet %ld, changed by %ld\n", (long)res.coins, (long)res.coins_change);
```

- `ember_vale_run()` needs about 8 KB of task stack.
- If you don't pass a panel, it sets up the ST7789 from Kconfig and releases
  it on return.
- `ember_vale_request_exit()` makes a running game save and return. It is
  safe to call from another task.
- `ember_vale_wallet_get(dir)` and `ember_vale_wallet_set(dir, coins)` read
  and write the coin count.
- The SPI bus must be free when the game starts if the game is to set up
  the LCD itself.

## Save folder

Every write goes to a temporary file and is then renamed, so a power cut
never leaves a half-written file.

| File | Contents |
|---|---|
| `save.dat` | progress: magic `EVSV`, u16 version, u16 length, FNV-1a checksum, then fields. A save that is corrupt or from the wrong version is ignored. |
| `wallet.json` | `{"coins":N,"lifetime_coins":M,"version":1}` |
| `status.json` | `{"game":"ember_vale","hearts":H,"crystals":C,"complete":0/1/2,"play_seconds":S,"deaths":D,"items":{...}}`, a summary the host can show without parsing the save |

**Coins into the host's money.** The host owns the exchange rate. After
`ember_vale_run()` returns, read `wallet.json`, credit the player, then
write back what is left with `ember_vale_wallet_set()`. The game reads
`wallet.json` on start-up and it overrides the coin count in `save.dat`, so
the host's value always wins. `example_host/main/main.c` cashes out 1:1 into
`/storage/host_bank.txt` and resets the wallet to 0, and the emulator's
"Cash out coins" button does the same.

## Changing the meme

1. Put any picture at `assets/meme.png`. It is scaled to fit 128x96.
2. Run `python3 tools/build.py`.
3. Rebuild.

The default is an original pixel-art shiba with "such wow" captions. The
vault's sign text is `sign_meme` in `tools/world.py`.

## Tested so far

- **Playtest bot:** with damage on, it reaches all 53 rooms, gets every
  item, the 3 hidden hearts, the fairy and meme rooms, beats both bosses and
  sees the ending in about 10 minutes of game time, then saves and exits.
  Screenshots and summaries are in `docs/playtest/`.
- **Compiler:** the core compiles warning-clean with gcc and emcc.
- **ESP-IDF:** the ESP-IDF 5.3.1 example host builds for esp32s3.
- **Not yet tested:** real hardware. Pin choices and panel orientation are
  the first things to check on the device.
